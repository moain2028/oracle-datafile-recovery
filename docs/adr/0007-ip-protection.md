# 0007 — حماية الملكية الفكرية: ما يُسلَّم للغير وما يبقى داخلياً

## السياق والمشكلة
ODR منتج تجاري للمالك. المستودع كان **عاماً** على GitHub (أي شخص يستطيع قراءة الكود، سجل الحقائق الثنائية LV-001..071، الدروس، وتنزيل الإصدارات). المالك يريد أن يجرّب خبير خارجي الأداة **دون** أن يحصل على ما يمكّنه من إعادة بنائها: الخبير يحتاج `odr.exe` وملفات تجربة وصفحة شرح — لا الكود ولا دفتر المختبر.

القيمة الحقيقية للمشروع ليست الثنائي بل **الحقائق المقاسة** (`docs/design/lab-verify.md`: إزاحات، قواعد، حدود، حالات تلف) ومنهجية الذهبي/الأحمر-الأخضر؛ هذه هي ما يجب ألا يخرج.

## الخيارات
1. إبقاء المستودع عاماً وإخفاء docs — غير كافٍ: الكود نفسه يشرح كل شيء (تعليقات مفصّلة بالتصميم).
2. مستودع خاص + إصدارات خاصة + أرشيف تجربة لا يحوي إلا الثنائي ووثائق الاستخدام.
3. مستودعان (خاص للكود، عام للتوزيع) — تعقيد إضافي لا يلزم الآن.

## القرار
الخيار 2، نُفِّذ في هذه الجلسة:
- **`gh repo edit --visibility private`** ✅ (تحقق: صفحة المستودع والـ Release يعيدان 404 بلا مصادقة).
- **محتوى أرشيف الإصدار** يقتصر على: `odr.exe`، `odr-corrupt.exe`، `LICENSE`، `README_TRIAL.md` (استخدام فقط)، `QUICKSTART_ar.md`، `TRIAL_KIT_ar.md`، `try_odr.*`. **لا** `CHANGELOG.md` (يحوي إزاحات وقواعد داخلية) ولا `README.md` الداخلي. ← تعديل `release.yml` **بيد المالك** (التوكن بلا `workflows`).
- **الثنائي**: `strip = "symbols"`، `debug = false`، LTO — موجودة. رسائل الرفض تذكر أرقام `LV-xxx` فقط (معرّفات بلا محتوى) — مقبول؛ لا مسارات مصدر لكودنا داخل الثنائي (مسارات `~/.cargo/registry` لمكتبات طرف ثالث فقط).
- **التسليم للخبير**: رابط Release خاص يتطلب دعوته كـ collaborator بصلاحية **Read**، أو إرسال الـ zip مباشرة. لا يُمنح وصولاً للكود.
- **الرخصة**: `LICENSE` = All rights reserved؛ `README_TRIAL.md` ينص صراحة على منع التوزيع والهندسة العكسية.
- `docs/field/` هي الوثائق الوحيدة المسموح خروجها؛ كل ما عداها داخلي.
